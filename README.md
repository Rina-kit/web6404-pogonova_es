# Лабораторная работа №2
## Описание сайта
Сайт кофейни **Coffee Compass**, которая находится в Самаре по адресу
1-го корпуса Самарского университета. 
Кроме меню и информации о кофейне на сайте есть страницы об истории кофе
и о способах его заваривания. Контент для истории взят из лонгрида, который был
разработан на иот "Цифровой дизайн".

## Страницы

**Главная (`index.html`)**
- Шапка с названиями страниц.
- Три карточки-ссылки на остальные страницы.
- О кофейне и что внутри.
- Наши зёрна.
- Почему мы рассказываем про историю кофе и ссылка на страницу истории.

**Меню (`menu.html`)**
- Четыре категории: кофе, холодные напитки, не кофе, сезонное меню.
- Каждая категория оформлена таблицей: название слева, объём по центру, цена справа.
- Сезонное меню выделено.

**История кофе (`history.html`)**
- Легенда о пастухе.
- Хронология распространения кофе по миру.
- Шесть интересных фактов о кофейных деревьях.
- Карта стран.

**Способы заваривания (`brewing.html`)**
- Таблица сравнения: турка, эспрессо, воронка, френч-пресс, аэропресс.
- Три правила вкусного кофе.

Во всех страницах сверху одна и та же шапка с логотипом и навигацией.

# Лабораторная работа №4

Сайт Coffee Compass из лабораторной №2 скопирован в `lab4`; исходные работы сохранены.

## Запуск

Требуется Node.js 18 или новее. Из папки `lab4` выполните:

```sh
npm start
```

Откройте http://127.0.0.1:3000. Установка пакетов не нужна: сервер использует встроенные модули Node.js. Открытие HTML напрямую позволяет просматривать страницы, но для отправки формы нужен сервер.

## Выполнение требований

- **Flexbox:** главная `index.html`, класс `page_flex`; вертикальная структура страницы, карточки `.cards`, блоки `.split` и карточки зёрен `.beans`.
- **Grid:** `menu.html`, `.menu-grid` — две колонки категорий; на телефоне одна колонка.
- **Цвета:** все значения цветов объявлены в `:root` файла `lab4/css/style.css`, остальные правила используют `var()`, включая градиенты, рамки и прозрачность.
- **CSS-анимация:** плавно падающий снег на всех пяти страницах сайта, `@keyframes snowfall`. Три размера снежинок, разные прозрачность, скорости, задержки и боковое движение создают глубину. Слой не перехватывает нажатия и отключается при `prefers-reduced-motion: reduce`.
- **Форма:** `visit.html` — `text`, `email`, `number`, `checkbox`, а также `select` и `textarea`; обязательные поля, ограничения длины и количества гостей, связанные подписи, статус отправки.
- **ООП:** `lab4/js/booking.js`, класс `TastingBooking`. Конструктор сохраняет значения из `FormData` в свойства `this`. Обработчик `submit` создаёт экземпляр через `new`, вызывает `printToConsole()` с `console.group` и `console.table`, затем выполняет POST `/api/bookings`. Стрелочная функция обработчика использована по материалам JavaScript.
- **Приём данных:** `server.js` проверяет поля и возвращает HTTP 201 с номером заявки. Это учебный обработчик без базы данных и рассылки писем: заявки на диск не сохраняются. При ошибке интерфейс сохраняет заполненные поля и позволяет повторить отправку.
- **Бонус БЭМ:** блоки `nav`, `hero`, `split`, `booking-form`; элементы `nav__link`, `split__text`, `booking-form__input`; модификаторы `nav__link_active`, `hero_home`, `split_reverse`, `booking-form__status_error`. Схема `блок__элемент_модификатор` соответствует лекции №5. Модификатор используется вместе с базовым классом.

Использованы лекции «4. JavaScript», «5. Modern CSS» и «6. OOP in JavaScript»: Flexbox и Grid, переменные, медиазапросы, БЭМ, `class`, `constructor`, `this`, методы и создание объекта через `new`. Содержание, изображения и оформление взяты из лабораторной №2. Библиотеки и фреймворки на сайте не используются.

## Проверка

Проверены все пять страниц в браузере на ширинах 1440 и 390 px: загрузка изображений, навигация, отсутствие горизонтального переполнения, раскладка Flexbox/Grid. Проверены запрет пустой отправки, создание объекта и табличный вывод в консоль, успешный POST (201), отклонение некорректной заявки (400), сообщение об ошибке сети и сохранение полей для повторной отправки.

## Контрольные вопросы

1. **Способы вёрстки:** обычный поток, блочная/строчная модель, Flexbox для одной оси, Grid для двух осей; позиционирование позволяет управлять положением отдельных элементов.
2. **БЭМ:** независимые блоки, принадлежащие им элементы и модификаторы состояния или вида; имена объясняют назначение класса и уменьшают конфликты стилей.
3. **Препроцессоры:** переменные, вложенность, примеси, операции и разделение файлов; результат компилируется в CSS. Здесь достаточно обычного CSS и custom properties.
4. **Контекст выполнения:** `this` зависит от способа вызова обычной функции; при вызове `booking.printToConsole()` указывает на `booking`. Стрелочная функция берёт `this` из внешней области.
5. **Создание объектов:** литерал `{}`, `Object.create`, функция-конструктор и `new`, класс и `new`. В работе применяется последний способ.
6. **Прототипы и классы:** поиск свойств идёт по цепочке прототипов. Методы класса находятся в его `prototype`; конструктор инициализирует экземпляр. Классы предоставляют удобный синтаксис поверх прототипной модели.
