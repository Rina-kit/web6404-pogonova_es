# Лабораторная работа №2
## Описание сайта
Сайт кофейни **Coffee Compass**, которая находится в Самаре по адресу
1-го корпуса Самарского университета. 
Кроме меню и информации о кофейне на сайте есть страницы об истории кофе
и о способах его заваривания. Контент для истории взят из лонгрида, который был
разработан на иот "Цифровой дизайн".

## Страницы

**Главная (`index.html`)**
- Шапка с названиями страниц.
- Три карточки-ссылки на остальные страницы.
- О кофейне и что внутри.
- Наши зёрна.
- Почему мы рассказываем про историю кофе и ссылка на страницу истории.

**Меню (`menu.html`)**
- Четыре категории: кофе, холодные напитки, не кофе, сезонное меню.
- Каждая категория оформлена таблицей: название слева, объём по центру, цена справа.
- Сезонное меню выделено.

**История кофе (`history.html`)**
- Легенда о пастухе.
- Хронология распространения кофе по миру.
- Шесть интересных фактов о кофейных деревьях.
- Карта стран.

**Способы заваривания (`brewing.html`)**
- Таблица сравнения: турка, эспрессо, воронка, френч-пресс, аэропресс.
- Три правила вкусного кофе.

Во всех страницах сверху одна и та же шапка с логотипом и навигацией.

# Лабораторная работа №3

В файле lab3/src/core.js реализованы функции:
- Проверка целого числа с помощью побитовых операторов.
- Получение массива чётных чисел от 2 до 20.
- Подсчёт суммы чисел через цикл и рекурсию.
- Вычисление факториала.
- Проверка степени двойки.
- Вычисление числа Фибоначчи.
- Создание функции, которая сохраняет результат операции.
- Создание генератора арифметической последовательности.
- Рекурсивное сравнение объектов.
